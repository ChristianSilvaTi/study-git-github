# Estudos de Git e GitHub

## 🇧🇷 Português

Este repositório foi criado para reunir meus **estudos, anotações e práticas sobre Git e GitHub**.

O objetivo é registrar os principais comandos e conceitos aprendidos durante meus estudos sobre **controle de versão, gerenciamento de repositórios e desenvolvimento colaborativo**.

Este projeto também serve como material de consulta e acompanhamento da minha evolução no uso do Git e GitHub.
